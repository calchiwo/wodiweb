Lists in HTML documents

We have 3 types of lists:

  1. Unordered lists
  2. Ordered lists
  3. Definition lists

Unordered lists

The unordered lists is created with the ul tag:

< ul>
    < li>First< /li>
    < li>Second< /li>
< /ul>

Example:

  • First
  • Second

Ordered lists

The ordered lists is similar but created with the ol tag:

< ol>
    < li>First< /li>
    < li>Second< /li>
< /ol>

The difference between the two is that ordered list has a number before each item

Example:

  1. First
  2. Second

Definition lists

Definition lists are a bit different. You have a title and a description

< dl>
    < dt>First title< /dt>
    < dd>First description< /dd>
    < dt>Second title< /dt>
    < dd>Second description< /dd>
< /dl>

Example:

First title
First description
Second title
Second description
