the script tag

The script tag is used to add JavaScript file into the page: inline code or loading an external javascript file using the src attribute

The script tag contains the invisble stuff and tells the browser how to load the whole page, so in my opinion it should be in the head element

the link tag

The link tag is used to link to an external CSS file to be loaded

The link tag is used to set relationships between a documents and other resources

The link tag is used with the rel attribute which stands for relationship.
