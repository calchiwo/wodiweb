The meta tags

Meta elements only have a starting tag

There are two types of meta tags

name

Used by:

- browsers

- search engine

- general tools

property

Used by:

Open graph (twitter, whatsapp, linkedin)

I personally think that meta tags shouldn't be grouped by how they look, but by who is reading them. because each meta tags is written for a specific reader

Examples

- Browser

- Google

- Twitter bot

- WhatsApp preview bot

7 buckets (7 systems)

A. Rendering control (Browser behavior)

These affect how the page behaves on the device

 < meta name="viewport" content="witdth=device-witdth, initial-scale=1.0"/>

Mental model:

How should this page physically appear on the screen

B. Search Engine System (how Google sees you)

These talk to Google

< meta name="description" content="A description here" /> 
< meta name="robots" content="index, follow" />
< meta name="googlebot" content="index, follow" />
< link rel="canonical" href="github.com/calchiwo/learning-the-web-properly" /> 
< title>A title here< /title >

Mental model:

If Google shows this page, what should it say about it?

If Google lists this in search results, how should it present and treat it?

C. Social link preview system

This control link previews and how your site looks when shared on platforms like WhatsApp, Linkedin, Twitter

Open graph (OG)

< meta property="og:url" content="https://site-name.com" /> 
< meta property="og:type" content="website" />
< meta property="og:title" content="A title here" />
< meta property="og:description" content="A description" />
< meta property="og:image" content="image-name.png"

Twitter tags

< meta name="twitter:image" content="https://site-name.com/image-name.png" />
< meta name="twitter:card" content="summary_large_image" />
< meta name="twitter:title" content="A title here" />
< meta name="twitter:description" content="A description here" />
< meta name="twitter:creator" content="@username"

Note:

The title/description should match the OG for consistency

Mental model

When my link travels, how does it sell itself?

D. Identity + Ownership system

This Identify creator and prove ownership to platforms

< meta name="author" content="..." />
< meta name="google-site-verfication" content="..." />

Mental model

Who owns this and can prove this and can prove it?

E. Favicon + Branding system

The job is to set tab icon

< meta name="icon" href="image.png" />

It's usually .ico or .png

Mental model

What does the user sees in the brower chrome?

F. Performance and resource system (preconnect)

This speeeds things up

And reduce latency when loding fonts

< link rel="preconnect" href="https://fonts.googleapis.com" />
< link rel="preconnect" href="https://fonts.gstatic.com" / crossorigin>

Mental model

Start connecting before I actually need it
Prepare resources early to reduce waiting time

G. Decoding system (UTF-8, charset)

This decodes HTML file into characters

UTF-8 is a rulebook that defines how characters turn (encode) into bytes stored in the disk in the writing phase (by the editor) and how the bytes stored in the disk turn (decode) into characters in the reading phase (by the browser)

Mental model
