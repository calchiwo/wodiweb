Learning HTML properly in one day

HTML is the language of the web

I learned HTML is a markup language used to structure documents for the web

I learned HTML is HyperText Markup Language

Web pages consist of:

Paragraphs, headings, subheadings, tags, fields, forms, some pictures and videos

What I learned about tags

The left angle and right angle brackets and characters (letters and numbers) in between them are known as tag

What I learned about elements

There are opening tags and closing tags

Elements is a pair of opening tags and closing tags and the content in between them
